# Teams-API
Api Football Teams

---

### Required

- Docker
- Gradle

### Stack:

- Java 21
- Spring Boot 3.3
- PostgreSQL 17
- Gradle 8.5

### Build executable Jar from project

```
./gradlew bootJar
```

### Start API

```
docker compose up -d
```

### Link to API Documentation

[Docs Teams-API](http://localhost:8080/swagger-ui/index.html)
